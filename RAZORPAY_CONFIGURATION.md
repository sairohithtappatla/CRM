
```

```

**Configuration Steps**:
1. Go to Settings → Webhooks
2. Click "Create New Webhook"
3. Paste webhook URL
4. Select events above
5. Set status to "Active"
6. Copy webhook secret for verification (optional)
7. Save

## 🔄 Switching from Test to Live

### Step-by-Step:

1. **Complete KYC**:
   - Submit business documents
   - Wait for approval (1-2 business days)

2. **Generate Live Keys**:
   - Go to Settings → API Keys
   - Generate Live Keys
   - Copy and store securely

3. **Update Webhook**:
   - Go to Settings → Webhooks
   - Create new webhook with production n8n URL
   - Enable same events as test
   - Activate webhook

4. **Update n8n Credentials**:
   - Replace test keys with live keys
   - Update webhook URL in workflows
   - Test end-to-end flow

5. **Monitor Closely**:
   - First 24 hours: Check every hour
   - Next 7 days: Daily monitoring
   - After 7 days: Weekly monitoring

## 📝 Troubleshooting Common Issues

### Issue: Webhook not working
**Solution**:
1. Check webhook URL is publicly accessible
2. Verify events are enabled
3. Check n8n workflow is active
4. Test with Razorpay's webhook testing tool

### Issue: Payment link expired
**Solution**:
1. Default expiry is 48 hours
2. To extend: Settings → Payment Links → Expiry Time
3. Or create new link programmatically

### Issue: Payment successful but no webhook
**Solution**:
1. Check webhook status in Razorpay dashboard
2. Look for failed delivery attempts
3. Verify n8n can receive HTTPS requests
4. Check firewall rules

### Issue: Customer can't complete payment
**Solution**:
1. Check if payment method is enabled
2. Verify settlement account is active
3. Check for downtime: https://status.razorpay.com
4. Try different payment method
